      OPTIONAL TOOL · LLM4DECOMPILE
      Decompile helper
      

      A small LLM4Decompile model that the Agent model (or you) can call as a tool. It turns one function’s pseudocode or assembly into a C suggestion that the agent reviews. It is not a second agent.
      LLM4Decompile was trained on Linux x86-64 GCC binaries, so output for Windows targets needs review. It needs a /completions endpoint; discovery does not download or load models.
      

      Add an OpenAI-compatible connection (for example a local llama.cpp or vLLM server) in Connections first.
